# 八股文总结

## 编译和链接过程中分别做了哪些工作？

编译链接过程，也就是源代码转换为可执行文件的过程。有预处理、编译、汇编、链接四个阶段。
1. 预处理(-E)：在预处理当中主要的工作是宏定义替换(#define)、头文件包含处理(#include)、条件编译(#if、#ifdef、#else)、移除注释(//)。
    - 宏定义替换：比如定义了一个字面值，在预处理的时候会进行文本替换；
    - 头文件展开：源文件当中，使用#include包含头文件，预处理阶段，会将头文件中的代码，原封不动的嵌入到当前的位置；
    - 根据不同的平台和C++不同版本，生成一些代码，选择不同的分支进行编译
gcc/g++中采用-E来生成预处理文件，后缀为(.i)的文件，可以叫做翻译单元。翻译单元将会作为编译阶段的输入文件(纯文本)。

2. 编译(-S)： 会进行词法，语法，语义的分析，最终代码优化生成汇编代码。在gcc/g++中采用-S来生成编译文件，后缀为(.s)的文件。这里生成符号表，词法/语法分析后，编译器构造抽象语法树，把源代码的结构转换为“语句—表达式—符号”的层级表示

3. 汇编(-c)：gcc/g++中采用-c来生成目标文件，具体就是将我们的汇编代码生成为目标硬件平台的二进制机械码(.o)文件

4. 链接(ld链接器)：当我们把所有源文件都生成机械语言二进制文件的时候，最后对他们进行链接，将多个文件以及他们所需要的库文件合并成可执行程序或共享库。**符号解析**，会将各个object文件的符号表合并形成一个全局的符号表，收集所有未解析的符号引用，然后在全局符号表中匹配，没查到就会报错(undefined reference)，如果找到会进入第二个步骤**地址重定位**，比如，代码段有一个未解析的函数引用，它的实际定义是在另外一个obj文件中，这里就会找到函数的实际地址进行一个修正定位。

**拓展的话：函数重载，多态，模版实例化，auto/decltype，lambda表达式**

## C语言编写代码检验机器大小端

```c
#include <stdio.h>

int main()
{
    unsigned int value = 0x12345678;
    unsigned char *ptr = (unsigned char*)&value;

    printf("按字节输出: %02x %02x %02x %02x\n", ptr[0], ptr[1], ptr[2], ptr[3]);

    if (ptr[0] == 0x78)
    {
        printf("当前机器是小端\n");
    }
    else if (ptr[0] == 0x12)
    {
        printf("当前机器是大端\n");
    }
    else
    {
        printf("无法判断\n");
    }

    return 0;
}
```

分析：将整型 `0x12345678` 存入内存后，以 `unsigned char*` 逐字节查看存放顺序。若最低地址存放最低有效字节 `0x78`，说明是小端；若最低地址存放最高有效字节 `0x12`，说明是大端。运行该程序即可判断当前机器的字节序。

**联合体检测法（面试常问的简洁写法）**

```c
#include <stdio.h>

int main()
{
    union
    {
        int a;
        unsigned char b;
    } u;

    u.a = 1;
    if (u.b == 1)
    {
        printf("小端：低地址存放低有效字节\n");
    }
    else
    {
        printf("大端：低地址存放高有效字节\n");
    }
    return 0;
}
```

解释：联合体成员共享同一段内存。`a` 赋值 `1`（0x00000001）后，若 `b`（最低地址处的一个字节）读到 1，说明低地址对应最低有效字节，即小端；反之则为大端。这里将 `b` 定义为 `unsigned char`，可避免不同平台上 `char` 有符号导致的歧义。
