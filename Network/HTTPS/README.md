# HTTPS

## HTTPS 就是 HTTP + SSL/TLS层

HTTPS = HTTP + SSL/TLS（安全套接层/传输层安全协议），在HTTP和TCP之间增加了一层加密层。

## 为什么需要HTTPS？

### HTTP协议的安全问题

**HTTP协议是明文传输的**，数据在传输过程中没有任何加密保护，存在严重的安全隐患：

1. **Cookie泄露风险(QQ盗号)**：
   - 用户在浏览器中输入账号、密码等信息，通过Cookie保存
   - HTTP传输时，Cookie以明文形式在网络中传输
   - **中间人攻击（Man-in-the-Middle）**：黑客、恶意WiFi、运营商等中间节点可以轻松截取和查看这些敏感信息

2. **数据篡改(运营商中间链接篡改)**：
   - 中间人可以修改传输的数据
   - 可能插入恶意代码、修改响应内容等

3. **身份冒充(非对称加密缺陷)**：
   - 无法验证服务器的真实身份
   - 可能连接到伪造的服务器

## SSL/TLS 介绍

**SSL（Secure Sockets Layer）安全套接层**：
- 全称：安全套接层
- 开发：由Netscape公司于1994年开发
- 版本：SSL 1.0（未发布）、SSL 2.0、SSL 3.0
- 状态：已被TLS取代，SSL 3.0在2015年被正式弃用（存在安全漏洞）

**TLS（Transport Layer Security）传输层安全协议**：
- 全称：传输层安全协议
- 开发：由IETF（互联网工程任务组）标准化
- 版本：TLS 1.0、TLS 1.1、TLS 1.2、TLS 1.3
- 状态：目前广泛使用的安全协议标准

**SSL与TLS的关系**：
1. TLS是SSL的继承者：TLS 1.0基于SSL 3.0设计，但做了重要改进，TLS可以看作是SSL的升级版本
2. 命名习惯：虽然现在主要使用TLS，但习惯上仍称为"SSL/TLS"，证书常被称为"SSL证书"，实际使用的是TLS协议

**TLS的优势**：
- 更强的安全性：修复了SSL的安全漏洞
- 更好的性能：TLS 1.3大幅减少了握手时间
- 标准化：由IETF标准化，更规范
- 持续更新：不断修复安全漏洞，推出新版本

**当前使用情况**：
- TLS 1.2：目前最广泛使用的版本
- TLS 1.3：最新版本，性能更好，安全性更高，正在逐步普及
- SSL 3.0及更早版本：已被弃用，存在安全风险

**总结**：TLS是SSL的现代化版本，现在HTTPS实际使用的是TLS协议，但习惯上仍称为SSL/TLS。

## 数据指纹(数据摘要)

**数据指纹（数据摘要）**：通过哈希算法将任意长度的数据转换为固定长度的唯一标识符，类似于数据的"指纹"。

**特点**：
1. **固定长度**：无论输入数据多大，输出的摘要长度固定（如MD5是128位，SHA-256是256位）
2. **唯一性**：理论上不同的数据会产生不同的摘要（哈希碰撞概率极低）
3. **不可逆性**：无法从摘要反推出原始数据（单向函数）
4. **雪崩效应**：原始数据的微小变化会导致摘要的巨大变化

**常见的哈希算法**：
- **MD5**：128位，已被认为不安全（存在碰撞漏洞），不推荐用于安全场景
- **SHA-1**：160位，已被弃用（存在安全漏洞）
- **SHA-256**：256位，目前广泛使用，安全性高
- **SHA-512**：512位，更高的安全性
